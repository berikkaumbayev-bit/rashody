РАСХОДЫ PWA V2 — БЕЗ NETLIFY / БЕЗ API

Эта версия не использует:
- Netlify Functions
- OpenAI API
- встроенную платную расшифровку голоса
- API-ключи

Работает локально:
- умный текстовый разбор расходов
- русский / казахский / английский / турецкий
- дата / сумма / категория
- запросы "сколько потратил..."
- Pivot
- автосохранение
- загрузка Excel
- вставка таблицы из Excel
- экспорт базы
- удаление и ручное редактирование

ГОЛОС
На телефоне нажмите на поле агента, затем используйте микрофон на клавиатуре.
Клавиатура превратит голос в текст, после чего локальный агент обработает текст.
Встроенной кнопки микрофона в приложении больше нет.

ВАЖНО ПРО ДАННЫЕ
Браузеры хранят localStorage отдельно для каждого адреса сайта.
Если вы уходите с Netlify на другой адрес:
1. В старом приложении нажмите "Выгрузить базу Excel".
2. В новой версии нажмите "Загрузить Excel".
Так данные перенесутся на новый адрес.

КАК ЗАПУСТИТЬ БЕЗ NETLIFY
Вариант A — компьютер:
- откройте index.html двойным кликом.
- база и локальный агент работают.
- установка PWA/service worker из file:// может быть недоступна.

Вариант B — телефон как устанавливаемое PWA:
- разместите эту папку на ЛЮБОМ статическом HTTPS-хостинге.
- серверные функции не нужны.
- можно использовать бесплатный GitHub Pages / Cloudflare Pages или другой static hosting.

ИНТЕРНЕТ
- База/Pivot/локальный агент/вставка таблицы работают без API.
- Для загрузки/выгрузки .xlsx используется библиотека SheetJS через CDN,
  поэтому для .xlsx лучше иметь интернет при первом открытии.
- Если CDN недоступен, экспорт автоматически может перейти в CSV.
